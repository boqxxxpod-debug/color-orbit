# COLOR ORBIT

スマートフォン縦画面向けの、同心円リングを回して色を揃えるオリジナルパズルゲームです。従来の20ステージと GATE TEST 5ステージを維持したまま、AUTO LOCKのゲーム性を試す LOCK TEST 5ステージを収録しています。

## 遊び方

- リングを右へスワイプ（または盤面右側をタップ）すると時計回り、左なら反時計回りに1スロット動きます。
- すべてのリングの色が同じ角度に並べばクリアです。小さな `↻` / `↺` 表示は連動先と方向を表します。
- `UNDO` は直前の1操作を、`RESET` はステージ開始時点を復元します。
- クリア手数をBFSによる最短手数と比較して星を獲得します。進捗・ベスト手数・設定はブラウザに保存されます。
- 設定では効果音と、色に記号を重ねる Color Help を切り替えられます。

## 技術構成

HTML5 / CSS3 / Vanilla JavaScript / SVGのみを使用しています。依存ライブラリ、CDN、バックエンド、ビルド処理はありません。`solver.js` は状態空間をBFSで探索し、最短操作列も返します。

## ローカルでの実行

`index.html` を直接開くか、リポジトリ直下で次を実行します。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。検証は `node tests.js` で実行できます。静的ファイルだけで構成されるため、そのままGitHub Pagesでも公開できます。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — モバイルファーストの表示・アニメーション
- `game.js` — 描画、入力、ゲーム進行、サウンド
- `levels.js` — Level 1〜20とリング連動定義
- `storage.js` — localStorageによる進捗・設定保存
- `solver.js` — BFS最短経路探索
- `tests.js` — 全レベルと状態遷移の自動検証


## GATE TEST 検証値

| Stage | 最短手数 | 最短解の swap 数 |
| --- | ---: | ---: |
| G1 | 3 | 1 |
| G2 | 4 | 1 |
| G3 | 6 | 3 |
| G4 | 8 | 3 |
| G5 | 10 | 3 |

全ステージは `node tests.js` で、解けること、回転だけでは解けないこと、および G3〜G5 の最短解で両方の GATE を使うことを検証しています。

## LOCK TEST 検証レポート

操作表記は `外/中/内 + CW（時計回り）/CCW（反時計回り）` です。各初期配置は外リングから順に、配列の先頭を12時として記載しています。

| Stage | 初期配置（外 / 中 / 内） | 最短 | 最短操作列 | LOCK順 |
| --- | --- | ---: | --- | --- |
| L1 | `RBY / RYB / RYB` | 1 | 外CW | 初期R → Y+B |
| L2 | `BRY / BYR / YRB` | 2 | 中CCW → 外CW | R → Y+B |
| L3 | `GBRY / RGBY / BRGY` | 2 | 外CW → 内CCW | 初期Y → R+G+B |
| L4 | `GYRB / RBGY / GRBY` | 3 | 外CW → 外CW → 内CCW | Y → R+B+G |
| L5 | `BPGYR / GYPBR / RGBYP` | 5 | 外CCW → 中CW → 内CCW → 外CW → 中CW | G → Y → P → B+R |

BFSは色配置とLOCK済みslotを状態として扱い、各回転後に同時AUTO LOCKを適用します。全到達状態から再度解を探索した結果は、L1〜L5でそれぞれ **8 / 78 / 27 / 284 / 8,880状態**、解不能状態はすべて **0** でした。したがって、この5配置では早期AUTO LOCKによる詰みはありません。

代表的な初手違いを含む最短手数は、L2の外CW・外CCW・中CWが各3手（最適比+1）、L5の外CW・中CCWが各6手（+1）です。L1、L3、L4には対称な別最短解もあり、必ずしも異なる初手が遠回りになるわけではありません。

自動テストでは、全5面の最短値とLOCK順、初期AUTO LOCK、複数色同時LOCK、LOCK済みslotの保持、解到達、全到達状態の非詰み、保存データのモード分離を検証します。既知の問題として、対称性の高いL1/L3/L4には複数の最短操作列があります。また、`prefers-reduced-motion` 環境ではアクセシビリティを優先して回転・LOCK演出がほぼ即時になります。
