# COLOR ORBIT

スマートフォン縦画面向けの、同心円リングを回して色を揃えるオリジナルパズルゲームです。従来の20ステージと GATE TEST 5ステージを収録し、リング同士が同方向・逆方向へ連動する仕組みを段階的に学べます。

## 遊び方

- リングを右へスワイプ（または盤面右側をタップ）すると時計回り、左なら反時計回りに1スロット動きます。
- すべてのリングの色が同じ角度に並べばクリアです。小さな `↻` / `↺` 表示は連動先と方向を表します。
- `UNDO` は直前の1操作を、`RESET` はステージ開始時点を復元します。
- クリア手数をBFSによる最短手数と比較して星を獲得します。進捗・ベスト手数・設定はブラウザに保存されます。
- 設定では効果音と、色に記号を重ねる Color Help を切り替えられます。

## 技術構成

HTML5 / CSS3 / Vanilla JavaScript / SVGのみを使用しています。依存ライブラリ、CDN、バックエンド、ビルド処理はありません。`solver.js` は状態空間をBFSで探索し、最短操作列も返します。

## ローカルでの実行

`index.html` を直接開くか、リポジトリ直下で次を実行します。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。検証は `node tests.js` で実行できます。静的ファイルだけで構成されるため、そのままGitHub Pagesでも公開できます。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — モバイルファーストの表示・アニメーション
- `game.js` — 描画、入力、ゲーム進行、サウンド
- `levels.js` — Level 1〜20とリング連動定義
- `storage.js` — localStorageによる進捗・設定保存
- `solver.js` — BFS最短経路探索
- `tests.js` — 全レベルと状態遷移の自動検証


## GATE TEST 検証値

| Stage | 最短手数 | 最短解の swap 数 |
| --- | ---: | ---: |
| G1 | 3 | 1 |
| G2 | 4 | 1 |
| G3 | 6 | 3 |
| G4 | 8 | 3 |
| G5 | 10 | 3 |

全ステージは `node tests.js` で、解けること、回転だけでは解けないこと、および G3〜G5 の最短解で両方の GATE を使うことを検証しています。
